1. LEMON: A Universal eBPF-based Volatile Memory Acquisition Tool for Modern Android Devices and Hardened Linux Systems

Date: 2026

Authors: Andrea Oliveri, Marco Cavenati, Stefano De Rosa, Sudharsun Lakshmi Narasimhan, Davide Balzarotti

Journal: Forensic Science International: Digital Investigation (DFRWS EU – Selected Papers from the 13th Annual Digital Forensics Research Conference Europe)

Abstract: LEMON is the first eBPF-based universal memory acquisition tool for hardened Linux and modern Android devices. It requires no kernel source code or code signing and supports x86_64 and ARM64 architectures. LEMON allows memory acquisition to local storage or over the network in standard forensic formats, enabling forensic analysis even on GKI-equipped Android phones.

Note: My contribution was primarily in implementing the eBPF-based memory dumping in Linux kernel (x86 architecture). Extension of the work was carried out by co-authors.

2. Remote Attestation of User-Space Applications at Runtime (Master Thesis)

Date: 09/2025

Author: Sudharsun Lakshmi Narasimhan

Supervisor: Dr. Lachlan Gunn, University Lecturer, Aalto University

Professor: Davide Balzarotti, EURECOM

Advisor: Dr. Jukka Ylitalo, Ericsson

Permanent Link: https://urn.fi/URN:NBN:fi:aalto-202510208274

Abstract: This thesis presents a framework for continuous runtime attestation of user-space processes. It securely binds process behavior to TLS session hashes and uses eBPF tracing and TPM-based signatures to detect anomalies. The system enables runtime monitoring with minimal performance overhead and demonstrates its relevance for Zero-Trust Architectures (ZTA) by continuously verifying process integrity and behavior.

3. Fabric Defect Detection Using YOLOv2 and YOLO v3 Tiny

Date: 11/2020

Authors: R. Sujee, Shanthosh Devaraj, Sudharsun Lakshmi Narasimhan

Publication: Advances in Intelligent Systems and Computing, pp. 196–204

ISBN: 978-3-030-63466-7

DOI: 10.1007/978-3-030-63467-4_15

Abstract: This study uses YOLOv2 and YOLOv3 Tiny to detect six types of fabric defects: Rust, Grease, Hole, Slough, Oil Stain, and Broken Filament. Both models are evaluated on a dataset collected for this research, highlighting their detection performance and practical applicability for industrial inspection.
